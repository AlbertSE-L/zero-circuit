# 阿瓦隆流程法官

规则改编自 [NANG-SAN-KHAM/indie-avalon](https://github.com/NANG-SAN-KHAM/indie-avalon)，基准提交 `09b39c49bddb8aa73d7734668ed74c137d9f674a`，保留 MIT 许可于 `LICENSE.indie-avalon`。

接入现有 Node HTTP 服务，替换 Socket.io/Vue 接口与 UI。沿用并改造角色视野、任务人数/失败门槛及组队、投票、任务、刺杀流程。补齐操作权限、投票值校验、好人不能出失败、5–10 人刺客配置，并且永不公开个人任务票。

- `config.mjs` 定义角色、5–10 人任务人数/阵营比例和版型。新增预设可修改 `presets`。自定义角色组合由房主在准备室配置，当前要求梅林与刺客各一名。
- `engine.mjs` 定义流程与按玩家过滤的数据视图。新特殊技能还需要在这里实现，新增角色说明不会自动产生技能。
- `handler.mjs` 管理身份令牌、版本冲突、房间存档和事件记录。
- `app.js` / `index.html` / `style.css` 是原创轻量中文手机界面，不携带上游图像素材或管理员密码。

房主选择人数、版型后分享链接，玩家就座；全员确认身份后依次组队、全员投票、队员秘密出任务票，三胜后由刺客刺杀。组队票在收齐后公开，任务只公布成功/失败总数。7 人及以上第 4 次任务须两张失败票才失败。

本地存档在 `.data/avalon/`，刷新可用浏览器保存的令牌恢复席位。同一地址浏览器可恢复座位。Render 免费实例磁盘不持久，重部署/实例替换后房间可能丢失；D1 持久化保存访问、建房、加入和开局事件，未用于本模块对局状态备份。
