# 零点回路 · Zero Circuit

面向同桌聚会的原创合作数字推理网页。2–5 人，主持人也是玩家。主持电脑运行服务，手机通过电脑 IP 加入；无需账号、数据库、云服务器或 npm 安装。

## 启动和加入

1. 双击 `start.cmd`，保持窗口打开（需要 Node.js 22+；本机脚本也能找到 Codex 附带的 Node）。
2. 主持电脑打开 `http://localhost:8790`，输入昵称、人数、关卡并创建房间。
3. 手机连接同一 Wi-Fi，访问启动窗口打印的地址，例如 `http://192.168.1.20:8790`。输入六位房间号和自己的昵称，或使用邀请链接。
4. 全员入座后，房主点击“分配线路”。每个玩家点“显示我的数字”查看自己的线路。

电脑地址可能因 Wi-Fi / DHCP 改变，以启动窗口为准。不要在手机上输入 localhost。访客网络、AP 客户端隔离、VPN 或防火墙都可能阻断访问。

防火墙需允许同一 Wi-Fi 网段访问主持电脑的 TCP 8790。

停止：前台启动时在窗口按 Ctrl+C；本次后台服务可运行 `powershell -ExecutionPolicy Bypass -File .\stop.ps1`。电脑休眠、关机或停止服务后，手机无法连接。没有设置开机自启。

## 核心规则

详见 `RULES.md`，游戏内也附有行动手册。

- 玩家看自己的数字，队友只能看位置及公开提示，不能直接报未公开数字或使用编码暗号。
- 按从小到大的固定位置推断，轮到自己时用一条自己的线路配对队友的一条线路。
- 蓝线同数字、琥珀线同颜色即可清除。猜错消耗容错并公开目标；碰红线立即失败。
- 一种类型的全部剩余线路集中在自己手里时，可用本地自检清除。
- 每人一次免费公开蓝线提示，以及一个单次原创技能。清除所有非红线即可获胜。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `modules/rules.mjs` | 发牌、排序、回合、配对、自检、胜负和玩家可见信息 |
| `modules/challenges.mjs` | 独立关卡配置，四关，包括 48 条蓝线的十二频段 |
| `modules/skills.mjs` | 技能名称、说明、目标要求和效果，包含五个原创技能 |
| `server.mjs` | HTTP、房间、身份凭据、版本冲突、权限和本机存档 |
| `public/` | 原创中文界面、手机布局、加入/主持流程和轮询同步 |
| `test/game.test.mjs` | 规则、各人数关卡、隐私、接口权限和重启恢复测试 |

新增同类关卡：在 challenges 中增加唯一 id 和参数；当前规则要求蓝线四份、琥珀线偶数份。新增技能：在 skills 中实现 apply，规则会按技能列表循环分配；关卡的 skills 字段目前仅为预留标记。新增完全不同游戏：实现新的规则适配器和对应前端；房间服务可复用，但当前界面及分发仍绑定本规则，尚不是即插即用的多游戏平台。

## 存档、重连与边界

- `.data/` 保存原子写入的 JSON 房间快照，重启恢复最近七天存档。同一浏览器和同一地址下刷新可恢复席位；不要清除站点数据或用无痕模式承载需要保留的席位。
- 浏览器凭据按地址隔离：localhost、127.0.0.1 和电脑 IP 被视为不同站点。请始终使用最初加入时的地址。
- 没有找回凭据功能。丢失凭据时，房主可中止本局，在准备室移除原席位后让玩家重新加入。
- 手机切换应用/窗口失焦时会隐藏私人数字；接口仅发该玩家自己的完整信息。主机拥有完整存档和程序控制权，不具备对抗主机作弊能力。
- HTTP 局域网通信未加密，限可信局域网，不应做公网端口映射。房间号不是密码，未满房间可被知道号码的人加入。
- `.data/` 包含身份凭据及私人线路，备份时妥善保存，不要随源码分发。
- 当前同步采用约 2.2 秒轮询，没有机器人、语音、二维码、在线状态判定或跨设备凭据迁移。

## 验证

`node --test`：六组测试覆盖普通/琥珀配对、红线、容错、技能、提示、自检、胜负、2–5 人三关发牌、玩家隐私、接口权限、重复操作版本冲突、失败操作回滚、磁盘恢复。

本机启动无需访问互联网。测试使用 Node 内置工具，接口测试需要允许本机监听和回环连接。

## 双游戏本地分支
运行 node server.mjs 或 start.cmd，只需一个进程。端口默认 8790，可用 PORT 覆盖。根路径为大厅，/circuit 是零点回路，/gang/ 是帮派。原有 /?room=房号 邀请仍有效。两款游戏分别管理房号和席位；帮派房间保存在 .data/gang，各步操作原子落盘。刷新原标签自动恢复；同一浏览器同一地址重新打开后可点击恢复最近座位。
